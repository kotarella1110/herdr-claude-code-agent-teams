# Changelog

All notable changes to this project are documented here. Entries are generated by [knope](https://knope.tech) from the change files in `.changeset/`.

## 0.1.5 (2026-11-18)

### Features

#### Show teammate names in the herdr sidebar

Each teammate now appears in herdr's agent sidebar under its own name instead of `claude`. The plugin also reports `$teammate`, `$team` and `$model` tokens for custom sidebar rows.

## 0.1.4 (2026-11-18)

### Features

#### Add a doctor action

The new `doctor` action checks the herdr and Claude Code versions, herdr's Claude Code integration, the locale and the state directory, and lists running leads with their teammate panes, routes and any tmux commands the plugin could not handle. It is also available as `herdr-claude-code-agent-teams doctor`.

## 0.1.3 (2026-11-18)

### Fixes

#### Keep a teammate's tmux ID and title after its pane is moved to another workspace

herdr gives a pane a new ID when you move it to another workspace. The plugin then reported the moved teammate to Claude Code as a new, untitled tmux pane. It now follows each pane by its herdr terminal ID, so a moved teammate keeps its tmux pane ID and title.

## 0.1.2 (2026-11-17)

### Fixes

#### Have the team lead spawn helpers as teammates

The lead's appended system prompt now tells it to spawn every helper with a name when asked for a team. Without a name, Claude Code ran helpers as background subagents that never got a herdr pane.

## 0.1.1 (2026-11-17)

### Features

#### Start teammates in other repositories

A teammate can now start in another directory and read that repository's `CLAUDE.md`, skills and settings. The team lead registers a directory for a teammate name with the new `route` subcommand before spawning it, and a teammate named after a git repository inside or next to the lead's directory starts there without registration. The lead is told how to do both when it starts.

## 0.1.0 (2026-11-17)

### Features

#### Run Claude Code agent team teammates as herdr panes

- A tmux-compatible layer that turns the tmux commands Claude Code issues for agent teams into `herdr pane` operations.
- The `open` action splits the focused pane and starts a team lead there; the `here` action starts one in the focused pane.
- The `configure` action opens the arguments passed to `claude` in an editor popup.
