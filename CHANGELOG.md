# Changelog

All notable changes to this project are documented here. Entries are generated by [knope](https://knope.tech) from the change files in `.changeset/`.

## 0.1.1 (2026-11-17)

### Features

#### Start teammates in other repositories

A teammate can now start in another directory and read that repository's `CLAUDE.md`, skills and settings. The team lead registers a directory for a teammate name with the new `route` subcommand before spawning it, and a teammate named after a git repository inside or next to the lead's directory starts there without registration. The lead is told how to do both when it starts.

## 0.1.0 (2026-11-17)

### Features

#### Run Claude Code agent team teammates as herdr panes

- A tmux-compatible layer that turns the tmux commands Claude Code issues for agent teams into `herdr pane` operations.
- The `open` action splits the focused pane and starts a team lead there; the `here` action starts one in the focused pane.
- The `configure` action opens the arguments passed to `claude` in an editor popup.
