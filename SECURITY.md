# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them through [GitHub's private vulnerability reporting](https://github.com/kotarella1110/herdr-claude-code-agent-teams/security/advisories/new). Include the version, your platform, steps to reproduce and the impact you expect.

You can expect an initial response within 7 days. Once a fix is released, the advisory will be published with credit to the reporter unless you prefer otherwise.
